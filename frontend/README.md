# Nitro Bot - Frontend

This is the frontend component of the Nitro Bot platform, built with React and Vite. It provides a highly interactive and responsive user interface for AI-driven interview preparation.

## Features

- **Dynamic Dashboards:** Real-time visibility into preparation progress and session history.
- **Interactive Interview Interface:** A immersive UI for live interview simulations with animated feedback.
- **Role-Based Setup:** Customized forms for defining target roles and experience levels.
- **Markdown Rendering:** Clean presentation of technical explanations and code snippets.
- **Secure State Management:** Context-based user authentication and data persistence.

## Technologies Used

- **React:** Component-based UI library.
- **Vite:** Next-generation frontend tooling for fast development.
- **Tailwind CSS:** Utility-first CSS framework for rapid UI development.
- **Framer Motion:** Animation library for smooth transitions and interactive elements.
- **React Router:** Declarative routing for single-page applications.
- **Axios:** Promise-based HTTP client for API communication.

## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Development Mode:
   ```bash
   npm run dev
   ```

3. Production Build:
   ```bash
   npm run build
   ```

## Structure

- `src/components`: Reusable UI components (cards, inputs, layouts).
- `src/pages`: Main application views (Dashboard, Live Interview, Auth).
- `src/context`: React Context providers for global state.
- `src/utils`: Helper functions, API configurations, and constant data.
